02 / Derivación

Modelado matemático paso a paso

El modelo concentra la masa térmica y las pérdidas de calor en una resistencia térmica y una capacitancia térmica equivalentes.

1

Balance de energía

Potencia que entra menos calor perdido es igual a la energía térmica acumulada.

Cₜ · dθ/dt = P − θ/Rₜ
2

Forma normalizada

Multiplicando por Rₜ se obtiene una ecuación diferencial de primer orden.

RₜCₜ · dθ/dt + θ = RₜP
3

Transformada de Laplace

Con condiciones iniciales nulas, la derivada se convierte en sΘ(s).

(τs + 1)Θ(s) = RₜP(s)
τ = RₜCₜ
4

Función de transferencia

La planta relaciona la potencia aplicada con la desviación de temperatura.

G(s) = Θ(s)/P(s) = Rₜ/(τs + 1)

Parámetros base del documento

Rₜ = 0.5 °C/W
Cₜ = 400 J/°C
Kp = 2
τ = RₜCₜ = 200 s

Transferencia base

G(s) = 0.5 / (200s + 1)

La prealimentación nominal es Kff = 1/Rₜ = 2 W/°C. Para un salto térmico de 220 °C desde 25 °C, la potencia base estimada es 440 W.

05 / Validación numérica

Código de GNU Octave

Script reproducible para construir las funciones de transferencia, comparar las respuestas y visualizar los polos. Requiere el paquete control.

clear all; clc; close all;
pkg load control;

% Parametros del modelo termico (supuestos de ingenieria)
Rt = 0.5;       % Resistencia termica [°C/W]
Ct = 400;       % Capacitancia termica [J/°C]
Kp = 2;         % Ganancia proporcional
tau = Rt * Ct;  % Constante de tiempo [s]

% Planta: temperatura incremental / potencia
s = tf('s');
G = Rt / (tau*s + 1);

% Lazo abierto con prealimentacion Kff = 1/Rt
Kff = 1/Rt;
Mla = Kff * G;

% Lazo cerrado proporcional con realimentacion unitaria
Mlc = feedback(Kp*G, 1);

% Respuesta al escalon unitario y polos
t = 0:1:1200;
figure(1);
step(Mla, Mlc, t);
grid on;
legend('Lazo abierto', 'Lazo cerrado');
title('Respuesta al escalon');
xlabel('Tiempo [s]');
ylabel('Temperatura normalizada');

figure(2);
pzmap(Mla, Mlc);
grid on;
legend('Lazo abierto', 'Lazo cerrado');
title('Mapa de polos');

% Para comparar temperaturas, escalar la respuesta por DeltaT
% y sumar la temperatura ambiente si se requiere.

Nota de consistencia: el script usa la realimentación proporcional estándar, cuyo valor final puede ser menor que la consigna. El simulador web muestra una comparación normalizada al mismo valor final para aislar el efecto de la rapidez, siguiendo la comparación ideal del informe. Son dos convenciones de análisis distintas; no deben confundirse.

06 / Cierre técnico

Conclusiones

El modelo permite entender el compromiso entre rapidez de respuesta, potencia disponible y rechazo de perturbaciones.

01. Prealimentación

Calcula una potencia base a partir del salto térmico esperado. Con el modelo exacto, compensa las pérdidas nominales y alcanza el objetivo ideal.

02. Realimentación

La medición permite corregir el error y responder a perturbaciones. Con Kp = 2, el informe compara un polo de −0.005 con uno de −0.01 s⁻¹ y una respuesta aproximadamente dos veces más rápida.

03. Límites del modelo

La potencia inicial puede acercarse al límite de 1000 W. Un modelo de primer orden, sensor ideal y parámetros supuestos no representa todas las dinámicas de un horno comercial.

Mejora futura

Incorporar acción integral para reducir el error residual, además de saturación del actuador, retardo de medición y perturbaciones térmicas. Validar los parámetros con datos de una zona real.
